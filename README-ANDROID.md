# Coast Rush Android

Application Android autonome basée sur le HTML corrigé, embarqué dans les assets de l'application.

- Lancement local via Android WebView / AndroidX WebKit AssetLoader (origine HTTPS locale).
- JavaScript, stockage local, audio et accès réseau activés pour le jeu et son multijoueur.
- Plein écran immersif.
- APK debug généré par GitHub Actions : onglet Actions, exécution **Build Coast Rush Android APK**, section Artifacts.

Pour compiler localement : Android Studio avec JDK 17, Android SDK 35 et Gradle 8.9.
